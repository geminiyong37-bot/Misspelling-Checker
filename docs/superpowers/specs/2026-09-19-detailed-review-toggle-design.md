# 추가 상세 검사 체크박스 설계

## 목표

기존의 날짜·숫자, 순화어, 문체·표현 체크박스를 하나의 `추가 상세 검사` 체크박스로 단순화한다. 기본 오타 검사와 선택적인 상세 검사의 구분은 유지하되 화면에서 상세 검사를 강조하지 않는다.

## 화면 구성

- 창 상단 제목과 같은 행의 오른쪽 끝에 `추가 상세 검사` 체크박스를 배치한다.
- 체크박스는 기본적으로 선택하지 않는다.
- 기존 선택 검사 영역과 체크박스 3개를 제거한다.
- `기본 꺼짐` 문구를 제거한다.
- 체크박스 글자는 `또는 아래 버튼을 눌러 선택` 안내 문구와 같은 10px 크기, 보통 굵기로 표시한다.

## 동작

- 체크하지 않으면 기존 기본 오타 검사만 실행한다.
- 체크하면 날짜·숫자 표기, 순화어, 문체·표현 검사를 모두 활성화한다.
- AI 검사에 전달되는 기존 옵션 이름은 유지하여 하위 검사 로직을 변경하지 않는다.

## 검증

- 체크박스가 기본적으로 꺼져 있는지 확인한다.
- 체크박스를 켰을 때 세 상세 검사 옵션이 모두 활성화되는지 확인한다.
- 기존 체크박스와 `기본 꺼짐` 문구가 화면에서 제거됐는지 확인한다.
- 체크박스 글자 크기가 파일 선택 안내 문구와 동일한지 확인한다.
